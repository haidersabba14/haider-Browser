# مدار — جميع مشاريع GitHub

لوحة عربية محمية بكلمة المرور، متصلة ببيانات GitHub الفعلية لجميع المشاريع العامة المملوكة للحساب `haidersabba14`، مع **١٣٦ أداة قابلة للتشغيل في ١٢ قسمًا**.

## ما يعمل

- اكتشاف مشاريع الحساب العامة تلقائيًا عبر API مع ترقيم الصفحات، وإضافة المشاريع الجديدة عند المزامنة دون تعديل المصدر. ظهرت ١٣ مشروعًا عند تنفيذ هذا التحديث.
- صفحة «تطبيقاتي» تعرض كل المشاريع مع البحث، الفرز حسب الاسم والنجوم والتحديث، التصفية بلغة الكود، وتقرير CSV للحساب كاملًا.
- اختيار المشروع من القائمة أو البطاقات يغيّر الإحصائيات والإصدارات والتقارير والأدوات الـ١٣٦ إلى سياق المشروع المختار. توجد حماية من ظهور نتائج طلب قديم بعد تبديل المشروع، وذاكرة مؤقتة منفصلة لكل مشروع ومورد.
- بيانات IPA المرفق وتأكيد عدم وجود أرباح تخص haider Browser فقط. المشاريع الأخرى تعرض معلومات GitHub الفعلية؛ تفاصيل IPA والأرباح غير متاحة حتى توفير مصدر خاص بها.

- جلب معلومات المستودع وعدادات تنزيل ملفات `.ipa` من GitHub Releases، مع ترقيم صفحات الإصدارات وملفاتها.
- عند عدم نشر ملف IPA في Releases تكون التنزيلات **غير متاحة**، ولا تُستبدل بصفر أو بأرقام تقديرية.
- haider Browser مجاني ولا يحقق أرباحًا حسب تأكيد صاحبه؛ هذا إقرار من المطوّر وليس قياسًا ماليًا من GitHub ولا يخص بقية المشاريع.
- فحص معلومات ملف المستخدم: `com.haider.browser`، الإصدار `0.2.1`، البناء `3`، الحجم وبصمة SHA-256، وبيانات التوافق وإقرار الخصوصية المستخرجة من ملفه.
- تحليل الإصدارات والملفات، تغييرات الكود، القضايا، طلبات الدمج، GitHub Actions، الفروع، المساهمين، بيانات IPA والتصدير وتخصيص اللوحة. جميع عناصر دليل الأدوات لها معالج تنفيذي.
- بحث عن الأدوات، تصنيفها وترتيبها، مفضلة، سجل استخدام، بحث وفرز نتائج الجداول، وتصدير نتائجها.
- تصدير CSV وTSV وJSON وMarkdown ونص وHTML مستقل، مع ذكر المصدر وحدود القياس.
- إعدادات محلية للمظهر وحجم النص والكثافة والحركة والأرقام وصفحة البداية والملاحظات ومهلة القفل. اختصار Ctrl/⌘+K يفتح بحث الأدوات.

## حدود الإحصائيات

GitHub يعد تنزيلات ملفات Releases، ولا يوفر عدد تثبيتات التطبيق أو المستخدمين الفريدين أو النشطين أو التقييمات أو الدول أو الأرباح. لا يمكن استعادة تنزيلات ملف أُرسل في محادثة أو نُشر خارج Releases. حذف ملف إصدار يحذف مساهمته من العدادات المعروضة. لا يوجد تاريخ تنزيلات يومي سابق، لذلك لا نوزع العدادات على فترات أو نختلق نسب نمو.

أدوات التغييرات والقضايا وطلبات الدمج والبناء والمساهمين تقرأ **حتى أحدث ١٠٠ عنصر لكل مصدر**؛ النتائج توثّق هذا النطاق. عداد تنزيلات IPA الأساسي يجمع صفحات الإصدارات والملفات كاملة ضمن حد ترقيم معلن؛ إذا تجاوز المصدر الحد يفشل الجلب صراحة بدل عرض مجموع جزئي. الإصدارات الأولية المنشورة تدخل في العداد، والمسودات لا تدخل.

الاتصال عام للقراءة فقط ولا يحتاج مفتاح GitHub لهذه المشاريع العامة. لا يمكن من خلال هذا الاتصال قراءة مستودعات خاصة، ولا تدّعي الواجهة أنها تعرضها. مسارات الخادم لا تسمح بجلب أي مستودع خارج قائمة الحساب المكتشفة. التخزين المؤقت حتى ٥ دقائق؛ حدود GitHub أو تعذر الشبكة تظهر كحالة خطأ. الأدوات لا تغيّر مستودع المستخدم ولا تضيف تتبعًا إلى المتصفح. البيانات المستخرجة من Privacy Manifest إقرارات مطوّر ولا تُثبت السلوك الفعلي.

## التطوير والتحقق

```sh
npm run build
npm test
python3 scripts/prepare-ios.py
```

ملف `web/features.mjs` يحتوي سجل الأدوات ومعالجاتها، ومصدر GitHub المشترك في `web/github.mjs`. لا توجد حزم بناء مطلوبة للخادم. اختبارات الخادم تستخدم مصدرًا وهميًا معزولًا داخل الاختبار فقط؛ الموقع المنشور يقرأ API الفعلي.

الأسرار المطلوبة في استضافة Sites: `DASHBOARD_PASSWORD` و`SESSION_SECRET`. لا تُكتب في المصدر. جلسة موقعة مدتها ٣٠ دقيقة، Cookie من نوع HttpOnly وSecure وSameSite=Strict. مهلة عدم النشاط المحلية يمكن تقليلها إلى ٥ أو ١٠ دقائق. حد محاولات الدخول ذاكرته محلية لكل Worker؛ استضافة الموقع خاصة بالمالك أيضًا.

## مشروع iOS

افتح `ios/Madar.xcodeproj` في Xcode 16 أو أحدث على Mac، وحدد Team وBundle Identifier فريدًا من Signing & Capabilities. يشترط iOS 17+. الواجهة محفوظة محليًا وتقرأ GitHub مباشرة عند الاتصال. كلمة المرور محددة بتجزئة داخل القفل المحلي، ويُقفل التطبيق عند الانتقال للخلفية. قائمة المشاريع والتبديل تعملان أيضًا في واجهة iOS. الإعدادات والمشروع الأخير يحفظان في UserDefaults؛ ملفات التقارير تُشارك عبر قائمة iOS.

لملف IPA قابل للتثبيت: اختبر التطبيق على جهاز، ثم Product → Archive → Distribute App وفق حسابك وشهادتك. يوجد أيضًا ملف GitHub Actions في `ios/.github/workflows/build-ios.yml` لبناء **IPA غير موقّع** بعد وضع مجلد iOS كمستودع مستقل. يحتاج الناتج إعادة توقيع مناسبة قبل التثبيت؛ ليس تطبيقًا جاهزًا للنشر في App Store.

**لم يُبنَ مشروع iOS أو يُختبر على محاكي هنا** لأن البيئة Linux ولا تحتوي Xcode. تم التحقق من ملفات المشروع وموارده ومنطق الويب وواجهات الخادم، ولم يتوفر اختبار بصري بمتصفح. لم يُعدّل أو يُعاد توقيع ملف haider Browser المرفق.
